# TPS Watchlist 0.2.4

TPS Watchlist `0.2.4` is a backward-compatible dashboard performance patch. It removes one redundant whole-vault discovery pass and DOM rebuild from the common first-open path without changing any released feature or fallback contract.

## Changes

- A newly created Watchlist view renders once through Obsidian's public `View.onOpen` lifecycle established by `WorkspaceLeaf.setViewState`.
- `openDashboard()` reveals that initialized leaf without immediately calling `render()` a second time.
- An already-open dashboard still receives exactly one explicit render, preserving fresh state when the command, ribbon, GCM action, settings shortcut, or public API reveals it again.
- View type/state, reveal behavior, row ordering and contents, search state, lifecycle and render error propagation, watch discovery, commands, settings, providers, GCM/Notifier/AI integrations, and persisted data are unchanged.

## Before/after evidence

The release comparator compiles and executes the real `openDashboard()`, `WatchlistView.onOpen()`, and watch-row discovery code from exact public `0.2.3` and the versioned candidate.

- First open over 1,000 Markdown files:
  - `0.2.3`: two renders and 2,000 definition parses.
  - `0.2.4`: one render and 1,000 definition parses.
  - Both produced the same ordered active/paused rows, one `setViewState`, and one reveal.
- Existing dashboard reveal: both versions rendered once, parsed 1,000 definitions, retained the same rows, skipped leaf creation, and revealed once.
- `setViewState`, first-open `onOpen` render, and existing-view render failures preserved the same rejection and reveal behavior.
- Across 300 first opens over 10,000 Markdown fixtures:
  - Dashboard renders: `600` to `300` (50% reduction).
  - Watch-definition parses: `6,000,000` to `3,000,000` (50% reduction).
  - Reveals: `300` to `300`.
  - Median per ten-open sample: `1.065 ms` to `0.544 ms` (48.9% faster).
  - p95 per ten-open sample: `1.111 ms` to `0.713 ms` (35.8% faster).

The benchmark hard-fails unless exact `0.2.3` renders a new dashboard twice, the candidate renders it once, definition parses are exactly halved, reveals and existing-view behavior are unchanged, and both median and p95 improve.

- Obsidian 1.12.7 was reloaded in `Obsidian Plugin Test Vault`; first open and reopen both rendered the empty dashboard without creating a watch or invoking **Check all**.
- Runtime-owned `data.json` remained absent.
- Production was not accessed or modified.

## Compatibility and limitations

- Minimum supported Obsidian version remains `1.10.0`.
- No settings or data migration is required.
- No command, provider, watch behavior, public API, GCM action, notification route, AI capability, or standalone fallback was removed.
- The dashboard still performs vault-wide watch discovery on each intentional render. This release removes only the accidental duplicate render; it does not introduce cache invalidation state.
