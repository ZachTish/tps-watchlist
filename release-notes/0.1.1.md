# TPS Watchlist 0.1.1

## Release intent

This is the first GitHub release of the existing `0.1.1` plugin for BRAT installation and **Latest**-release tracking. The packaging work does not change shipped runtime behavior or data formats.

## Included behavior

- Contract-native page, JSON, RSS, and Atom monitoring with silent baselines and deterministic transition deduplication.
- Isolated concurrent watch checks, atomic event delivery, failure escalation, Controller-aware scheduling, and optional Notifier/GCM/AI Gateway integrations.
- Private-repository installation through BRAT with a fine-grained GitHub token limited to **Contents: Read-only**.

## Compatibility

- Minimum Obsidian version: `1.10.0`.
- Desktop and mobile are supported; scheduled checks run only while the responsible Obsidian instance is active.
- No migration is required from the existing `0.1.1` runtime.

## Validation

- `npm test`: passed `15/15` tests and its nested production build.
- Required separate `npm run build`: passed TypeScript and esbuild production bundling.
- Test-vault deployment: `[runtime-deploy] target=test ... unchanged`; the final source artifacts are byte-identical to the installed test runtime.
- This release candidate is prepared from the test-vault source and has not been promoted to production by this packaging pass.

## Known limitations

- Private BRAT installs require the GitHub token on each device; never store that token in the vault or repository.
- Page monitoring does not execute client-side JavaScript and can be unreliable against bot protection or unstable selectors.
- Monitoring stops when the responsible Controller/Obsidian instance is closed or suspended.
- Cross-device manual check requests are not routed through the Controller sync protocol.
