# TPS Watchlist 0.1.2

This patch separates settings intent from volatile watch state so neither overwrites the other.

## Changes

- State writes preserve current settings and unknown data; settings writes preserve current states, synchronized unrelated preferences, and unknown fields.
- Settings merges use a local baseline, retaining rapid change/revert intent and allowing queued work to continue after an earlier failure.
- Failed reads remain fail-closed.

## Compatibility and validation

- Minimum Obsidian: 1.10.0; desktop and mobile supported; no manual migration.
- Focused core/persistence tests and full declared suite: 20/20 passed; TypeScript and diff checks passed.
- A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; Watchlist registered normally and no runtime settings file was created or replaced.
- Scheduled monitoring still requires an active responsible Obsidian instance.
