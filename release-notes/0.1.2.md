# TPS Watchlist 0.1.2

This patch separates settings intent from volatile watch state so neither overwrites the other.

## Changes

- State writes preserve current settings and unknown data; settings writes preserve current states, synchronized unrelated preferences, and unknown fields.
- Settings merges use a local baseline, retaining rapid change/revert intent and allowing queued work to continue after an earlier failure.
- Failed reads remain fail-closed.
