# TPS Watchlist 0.2.1

TPS Watchlist `0.2.1` is a backward-compatible discovery and batch-efficiency patch. It removes intermediate watch-row collections and repeated front-of-array worker claims without changing monitoring behavior or persistence.

## Changes

- Vault-wide watch discovery parses each Markdown file once and appends valid rows directly in vault order.
- Concurrent batches retain the same shallow definition snapshot and claim the next item with a shared local index.
- Worker limits, per-watch execution, completion-order results, persistence/recovery, provider behavior, settings, and stored state are unchanged.

## Performance evidence

- Row construction changes from `map`/`filter`/`map` intermediates to one ordered pass.
- Batch claiming changes from repeated `Array.shift()` compaction to constant-time indexed access.
- The only new mutable value is a function-local index; no plugin state, cache, queue service, fallback, timer, or schema was added.

## Validation

- `npm test`: all 26 declared checks passed.
  - Twenty-two core behavior tests.
  - Four routed-settings contracts.
- Executable regressions cover file order, one definition parse per file, structural snapshot isolation, worker concurrency, and completion-order results.
- The concurrency regression passed 50 consecutive stress runs during review.
- A separate final `npm run build` passed and deployed only to `.obsidian/plugins/tps-watchlist` in the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; commands registered and the empty Watchlist dashboard rendered.
- No watch was created, no check or network request ran, and runtime-owned `data.json` remained absent.
- Production was not accessed or modified.

## Compatibility and limitations

- Minimum supported Obsidian version remains `1.10.0`.
- No settings or data migration is required.
- Watch discovery must still inspect the vault's Markdown files; this patch intentionally adds no invalidation cache.
- Result order remains completion order, as before.
