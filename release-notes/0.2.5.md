# TPS Watchlist 0.2.5

TPS Watchlist `0.2.5` is a backward-compatible JSON-provider performance and reliability patch. It removes a duplicate resolver that only tests used, moves those tests onto the live provider implementation, and avoids two temporary token arrays per JSON observation.

## Changes

- Export the existing live JSON-provider path resolver for direct internal regression testing.
- Route `fromJson()` and the core suite through that one implementation.
- Remove the unused near-duplicate resolver from `src/core.ts`.
- Trim and skip raw path tokens during one traversal instead of allocating `map()` and `filter()` intermediates.
- Add no cache, state, fallback, retry, monkeypatch, listener, timer, persisted field, or unsupported Obsidian behavior.

## Before/after evidence

- Actual exact `0.2.4` and candidate provider modules produced zero value or exact error-message mismatches across 500,060 supported JSON/path cases.
- The corpus covered empty and `$` roots, dot paths, numeric brackets, single- and double-quoted keys, whitespace, empty segments, arrays, objects, nulls, primitives, missing keys, and paths that stop on non-objects.
- The focused regression now imports the function used by real JSON watches and verifies root, nested, bracket, quoted-key, empty-segment, missing-key, and non-object behavior.
- Across 31 interleaved rounds of 300,000 nested resolutions, median time changed from 197.263 ms to 182.981 ms and p95 from 198.710 ms to 183.997 ms—improvements of 7.24% and 7.40%.
- Root-path resolution remained within ordinary benchmark variance.
- The combined runtime source is 22 lines smaller and the production bundle shrinks from 56,698 to 56,691 bytes.

These timings isolate JSON-path resolution. Provider transport, response parsing, pattern extraction, fingerprinting, persistence, events, notifications, and dashboard work are unchanged.

## Validation

- Exact public `0.2.4` was pinned at commit `350fd0c7a0d0b26519bb057e327d7825e07881bf`.
- The untouched baseline passed all 30 core tests, four settings contracts, TypeScript, and its production build with runtime deployment suppressed.
- The candidate focused live-provider regression passes.
- The final versioned release tree passes all 30 core tests, four settings contracts, TypeScript, and the mandatory separate production-mode build.
- The final artifacts deploy byte-identically only to the registered Obsidian Plugin Test Vault.
- Obsidian 1.12.7 renders the existing empty dashboard without creating a watch or invoking **Check all**.
- Runtime-owned `data.json` remains absent. Production was not accessed.

## Compatibility and limitations

- Minimum supported Obsidian version remains `1.10.0`.
- JSON path grammar, resolved values, exact failures, providers, conditions, watch definitions, settings, state, events, notifications, integrations, and public APIs are unchanged.
- No settings or data migration is required.
- Path parsing remains the intentionally small released dot/bracket resolver; JSONPath filters, recursive descent, wildcards, unions, and expressions are not added.
